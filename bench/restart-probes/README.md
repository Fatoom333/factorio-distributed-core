# Пробы «перезапуска сжатой очереди» (09.10.2026)

Инструменты, которыми разбиралось расхождение `compressed-restart-*` (docs/model-fidelity.md, п. 1;
docs/mechanics/belts.md, «Перезапуск сжатой очереди»). Модель ядра они не используют — читают
только эталоны игры, поэтому другие расхождения модели им не мешают.

| файл | что делает |
|---|---|
| `gen.py <папка> <набор>` | генерирует сцены наборов `a`…`i` (лента на восток, источники с севера, сток в конце; варианты — см. код). Снимать: `fuzz_capture --scenes <папка> --out <папка прогона>` |
| `lag.py <dump> <scene> [--verbose]` | ищет в эталоне пары «передний сдвинулся, задний (стоявший вплотную, 64) мог, но не сдвинулся» — «запоздалый перезапуск»; печатает места (тайл от головы `k`, `p`) |
| `bnd.py W <папки>` | по каждой сцене и границе тайла: перезапуски с лагом / без лага при движении в тайлах `[k, k+W)` в предыдущем тике |
| `evt.py <scene> <dump> K` | хронология событий на границе `K`: `R` — перезапуск, `F` — поток, `L` — лаг |
| `replay.py PART SLEEP <папки>` | проверка гипотез «сегменты линии + список активных» прогоном по эталону (состояние игры t-1 → шаг лент по гипотезе → сравнение с t). Все проверенные варианты (см. docs) отвергнуты |

Наборы, снятые 09.10 (≈ 230 сцен, вне git): `b` — источники на каждом тайле, N = 6…40, обычные и
быстрые ленты, оба порядка постройки; `c`/`d`/`e`/`g`/`h` — разное расположение источников;
`f` — дополнительный источник с 1 предметом, другая полоса, сток посреди ленты; `i` — сжатый
непрерывный поток. Выводы — в docs/mechanics/belts.md.
