# factorio-distributed-core

Серверное ядро проекта Factorio Distributed (Rust).

Своё открытое ядро считает мир Factorio вместо ванильного мультиплеера. В ванильном мультиплеере
каждый клиент считает весь мир и самый слабый тормозит всех. Здесь мир режется на куски,
и куски считаются на машинах игроков. Factorio у игрока с модом
[factorio-distributed-mod](https://github.com/Fatoom333/factorio-distributed-mod) только рисует
окно вокруг того места, куда игрок смотрит, а ядро управляет ею через RCON.

**Почему так, а не модом к самой Factorio:** движок и сетевой протокол Factorio закрыты, а у мода
и у RCON есть только моддинг-API. Подробно — [docs/why.md](docs/why.md).

Архитектура: [docs/architecture.md](docs/architecture.md). Мир режется по самым тонким рёбрам
(поезда, дроны, подсистемы), и на каждом шве работает предсказание с откатом (rollback).

Статус: замеры сделаны ([bench/RESULTS.md](bench/RESULTS.md)), архитектура зафиксирована.
Следующий этап — M0: модель лент, сундуков и манипуляторов со сверкой потиково с настоящей игрой.

Сборка: `cargo build`.
