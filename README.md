# factorio-distributed-core

Серверное ядро проекта Factorio Distributed (Rust).

Внешнее ядро считает мир Factorio вместо ванильного мультиплеера (где каждый клиент симулирует весь мир и самый слабый тормозит всех).
Каждый игрок запускает локальный Factorio в режиме сервера с модом
[factorio-distributed-mod](https://github.com/Fatoom333/factorio-distributed-mod); ядро управляет им через RCON.

Идея архитектуры: резать граф зависимостей по самым тонким рёбрам (поезда, дроны, подсистемы),
каждый шов лечить предсказанием с откатом (rollback).

Статус: заготовка. Первый прототип — один конвейер и сундук: ядро двигает предметы, клиент показывает.

Сборка: `cargo build`.
