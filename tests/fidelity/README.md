# Сверка модели с игрой (M0)

Эталоны снимаются из настоящей Factorio 2.0 (base + space-age) модом `factorio-distributed`
и лежат здесь: `<name>.scene.json` (сцена) и `<name>.dump.jsonl` (состояние каждый тик).

Снять заново: поднять сервер (`bench/run-server.ps1`, см. `bench/README.md`) и
`cargo run --release --bin scene_capture -- tests/fidelity/<name>.scene.json`.

## Сцена

```json
{"name": "straight-belt", "ticks": 1200,
 "entities": [{"name": "wooden-chest", "position": [0.5, 0.5], "items": {"iron-plate": 200}},
              {"name": "inserter", "position": [1.5, 0.5], "direction": "west"},
              {"name": "transport-belt", "position": [2.5, 0.5], "direction": "east"}]}
```

`position` — центр сущности в тайлах, `direction` — как в игре.
Мод строит сцену на отдельной поверхности `fd-scene` (плитка lab) и ставит бесконечное питание
(подстанции и источник энергии выше сцены, y = -6).

## Эталон

Одна строка JSON на тик, t = 0 .. ticks включительно (ticks + 1 строк):

```json
{"t": 0,
 "belts": [{"pos": [2.5, 0.5], "lines": [[{"item": "iron-plate", "p": 64}], []]}],
 "inserters": [{"pos": [1.5, 0.5], "held": "iron-plate", "held_count": 1, "hand": [128, 128]}],
 "chests": [{"pos": [0.5, 0.5], "items": {"iron-plate": 199}}]}
```

Сущности в массивах идут в порядке появления в сцене. `lines[0]` — линия 1, `lines[1]` — линия 2
(`get_transport_line(1/2)`). `hand` — абсолютные координаты `held_stack_position`, в 1/256 тайла.

## Что значит «тик 0»

Снимок t = 0 — сундуки только что заполнены, манипуляторы запитаны и прогреты (не меньше 60 тиков
после постройки), ни одного обновления игры с предметами ещё не было. Снимок t = k — состояние после k
обновлений игры. Все снимки читаются в `on_tick` в одной и той же фазе тика.

## Факты, снятые с эталонов

- `p` — расстояние **до конца тайла** ленты (по ходу движения) в 1/256: предмет едет, `p` падает на
  скорость ленты за тик (8 / 16 / 24), при переходе на следующий тайл `p` прибавляет 256.
  Упёршиеся в конец предметы стоят на p = 0, 64, 128, 192 (шаг 64).
- Направление манипулятора: `direction` — сторона, **откуда он берёт** (`west` — берёт с запада,
  кладёт на восток). Поднимает с `pickup_position` = центр соседнего тайла в этом направлении,
  кладёт в `drop_position` на 0.199 тайла дальше центра противоположного тайла (x = 2.699 для манипулятора в 1.5).
- Манипулятор на ленту кладёт на дальнюю от себя линию; при кладке «в лоб» (вдоль ленты) — на линию 2.
